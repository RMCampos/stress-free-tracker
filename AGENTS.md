# AGENTS.md - Stress-Free Tracker

## Project Overview

A Progressive Web App (PWA) for tracking stress-free days. Users log days they felt stressed, visualize them on a calendar, and monitor streaks and monthly stats. Data is stored locally in `localStorage`.

**Live URL**: https://stress-free-tracker.lightroasted.vps-kinghost.net

## Tech Stack

- **Vite** (^8.0.16) - Build tool and dev server
- **vite-plugin-pwa** (^1.3.0) - PWA support (service worker, manifest, offline caching)
- **Vanilla JavaScript** - No frameworks
- **CSS** - Plain CSS with mobile-first responsive design

## Architecture & Data Flow

### State Management
- **No framework** - direct DOM manipulation
- **Global state** in `index.js`:
  - `bugDates`: Array of ISO date strings (YYYY-MM-DD) when user reported stress
  - `startDate`: ISO date string when tracking began (defaults to today)
  - `currentViewDate`: Date object for calendar navigation

### localStorage Keys
- `bugDates`: JSON array of stressed day dates
- `startDate`: ISO date string of first app use

### Data Flow
1. On load: `init()` reads localStorage → updates DOM
2. User clicks "Report Stress": `reportBug()` → adds date to `bugDates` → saves to localStorage → re-renders calendar and stats
3. Calendar navigation: Modifies `currentViewDate` → re-renders calendar grid

### Key Functions

| Function | Purpose |
|----------|---------|
| `init()` | Entry point - loads data, renders UI |
| `reportBug()` | Records today as a stressed day (with confirmation) |
| `renderCalendar()` | Builds 6-week calendar grid with month navigation |
| `createDayElement()` | Creates individual day cell with styling classes |
| `updateStats()` | Updates total bugs, longest streak, current month count |
| `calculateLongestStreak()` | Computes longest gap between stressed days |
| `showUpdateNotification()` | Modal confirmation dialog (reused for confirmations) |

## Code Conventions

### Naming
- DOM element IDs: camelCase (`daysCounter`, `calendarGrid`)
- CSS classes: kebab-case (`calendar-day`, `bug-day`, `other-month`)
- Functions: camelCase, verbs (`reportBug`, `updateStats`)
- State variables: camelCase (`bugDates`, `currentViewDate`)

### Date Handling
- **Storage**: ISO format `YYYY-MM-DD` (via `toISOString().split('T')[0]`)
- **Comparison**: Use `Date` objects for arithmetic, string comparison for inclusion checks
- **Display**: Full month names in calendar title (array in `renderCalendar()`)

### CSS Patterns
- Mobile-first with `@media (max-width: 768px)` breakpoint
- Gradient backgrounds using `linear-gradient(135deg, ...)`
- Glassmorphism effect: `backdrop-filter: blur(10px)` with semi-transparent white
- Flexbox for centering, CSS Grid for calendar (7 columns)
- Hover animations: `transform: translateY(-5px)` with `transition: all 0.3s ease`

### DOM Structure
- Calendar: 7-column grid (Sun-Sat headers + 6 weeks of days)
- Day cells: `.calendar-day` with conditional classes:
  - `.other-month` - days from prev/next month (faded)
  - `.today` - current day (highlighted purple)
  - `.bug-day` - stressed day (red background + 😡 emoji via `::after`)

## PWA Considerations

- **Service worker**: Auto-registered via `virtual:pwa-register`
- **Offline ready**: Toast notification shown via `onOfflineReady` callback
- **Manifest**: Configured in `vite.config.js` with theme colors, icons
- **Caching**: Workbox caches all JS/CSS/HTML/PNG/SVG, plus Google Fonts

## Gotchas & Non-Obvious Patterns

### Date String Conversion
`bugDates` is stored as ISO strings but calendar compares using `new Date(dateString)` to handle timezone edge cases. Always pad month/day with `String(...).padStart(2, '0')`.

### Global Function Exposure
Functions called from HTML `onclick` handlers must be explicitly exposed on `window`:
```javascript
window.reportBug = reportBug;
window.previousMonth = previousMonth;
window.nextMonth = nextMonth;
```

### Confirmation Dialog Reuse
`showUpdateNotification()` is dual-purpose: it shows PWA update notifications AND confirmation dialogs for "Report Stress". The message span is accessed by class name and updated dynamically.

### Streak Calculation Logic
- If no stressed days: streak = days since `startDate`
- Longest streak calculated between consecutive stressed days (minus 1)
- Current streak = days since last stressed day

### Calendar Grid Size
Always renders 42 cells (6 weeks × 7 days) to have consistent layout. Previous/next month days fill empty slots and are styled with `.other-month`.

## Testing
